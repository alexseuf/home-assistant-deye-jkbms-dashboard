# Dashboard Mock-ups

Dieses Verzeichnis enthält die aktuellen, herstellerneutralen Mock-ups des Dashboards.

Aktuelle Dateien:

- `01-aktuelle-werte.svg`
- `02-historische-werte.svg`
- `03-summierte-werte.svg`
- `04-einstellungen-wechselrichter.svg`
- `05-einstellungen-jk-bms.svg`

Die neuen SVG-Mock-ups zeigen das Multi-Wechselrichter-Konzept mit **Wechselrichter 1–3**. Als konkrete Referenzprofile sind Deye/SolarModbus V2 und Solis Modbus von Pho3niX90 vorgesehen; ein dritter Wechselrichter kann z. B. Hoymiles sein.

Die älteren PNG-Dateien bleiben im Repository als historische Entwurfsstände erhalten, werden aber nicht mehr auf der Projekt-Startseite verwendet.

Entity-Mapping und Beschriftungen in der produktiven YAML bleiben maßgeblich.
