# Dashboard Mock-ups

Die Mock-ups stammen aus dem ursprünglichen Deye-basierten Entwurf. Die aktuelle Dashboard-Struktur ist herstellerneutral und unterstützt bis zu drei Wechselrichter.

Der vierte Reiter heißt produktiv **Einstellungen Wechselrichter**; ältere Mock-up-Dateinamen mit `deye` bleiben lediglich als historische Referenz bestehen.
